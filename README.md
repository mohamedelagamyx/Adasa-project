# عدسة (Adasa) - مدونة التصوير الفوتوغرافي

مدونة عربية متخصصة في فن وتقنيات التصوير الفوتوغرافي، مبنية باستخدام React و Vite و Tailwind CSS.

## المميزات

- واجهة عربية متكاملة تدعم اتجاه الكتابة من اليمين إلى اليسار (RTL) مع خطوط مخصصة.
- تصفح وتصنيف المقالات مع نظام بحث فوري متقدم.
- فلترة متعددة حسب التصنيفات وتبديل طريقة العرض (شبكة / قائمة).
- صفحات تفاصيل المقالات مع مقالات ذات صلة وعلامات مخصصة.
- تصميم متجاوب وسريع على كافة الشاشات والأجهزة.
- مهيأ للنشر الفوري على منصة Vercel مع قواعد إعادة التوجيه للصفحات الفردية (SPA Rewrites).

## التقنيات المستخدمة

- **React 18**
- **Vite 6**
- **React Router 6**
- **Tailwind CSS 3**
- **Lucide React** (الأيقونات)

## التشغيل محلياً

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```

3. بناء نسخة الإنتاج:
```bash
npm run build
```

## النشر على Vercel

المشروع يحتوي على ملف `vercel.json` لإدارة التوجيه الداخلي للمسارات تلقائياً. يمكن ربط مستودع GitHub مباشرة بـ Vercel ليتم البناء والنشر تلقائياً بالأمر:
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
